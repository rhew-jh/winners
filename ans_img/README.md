# ans_img — 빠른정답 그림 저장소

빠른정답 시트(`WINNERS_수학빠른정답_v1`)의 정답이 `(그림)`처럼 그림인 문항의 정답 그림을 여기에 둡니다. 웹앱(`math-wrong.html` · `english-console.html`)은 정답 칩을 누르면 이 폴더의 파일을 불러와 띄웁니다. 그림이 아직 없으면 화면은 깨지지 않고 "그림 준비 중" 안내만 보여 줍니다.

## 1. 지금 들어 있는 그림 (2026-11-27 · 247장)

|---|---|---|---|---|

파일명 규칙은 `{교재키}_p{정답지쪽:02d}_{문항:02d}.png` 입니다(같은 정답지 쪽에 같은 번호가 여러 단원에 있으면 `-2`, `-3` 접미). **파일 이름의 쪽은 크롭 원본 그대로 정답지 PDF 쪽**이고, 앱이 쓰는 쪽은 `manifest.json`의 **본문 쪽**입니다. 둘은 다르니 파일 이름만 보고 쪽을 판단하지 마세요.

## 2. 앱이 파일을 찾는 순서 (`ans-img.js` v3)

1. `manifest.parts[교재키][평가편][쪽][문항]` — 화면이 5번째 인자로 `단원평가`/`학업성취도평가` 힌트를 준 경우
2. `manifest.books[교재ID]` → `[본문 쪽]` → `[문항]`
3. `books[교재키]` (교재ID의 `/`→`__`, 특수문자·공백→`_`)
4. `titles` 별칭표에서 **교재명**으로 폴더 키 찾기 → `books[그 키]`
5. **여기까지 와서도 없으면**: manifest에 그 교재가 등록돼 있으면 파일 이름 규칙으로 추측하지 않고 "그림 준비 중"을 띄웁니다(파일 이름이 정답지 PDF 쪽이라 다른 쪽 그림이 뜨는 것을 막습니다). manifest에 없는 교재만 예전 규칙 경로 `ans_img/{교재키}/{교재키}_p{쪽:02}_{문항:02}.png` → `ans_img/{교재ID키}/{쪽}p_{문항}.png` 순으로 시도합니다.

화면이 `WINNERS_ANSIMG.open(bookId, 쪽, 문항, 교재명, 평가편힌트)`처럼 **교재명을 함께 넘기면**, 교재ID가 나중에 정해져도 4번 별칭표로 그림이 연결됩니다. `ans-img-test.html`에서 눈으로 확인할 수 있습니다.

## 3. manifest.json 구조

```json
{
  "meta": {
    "pageBasis": "body_page",
    "images": 247,
    "parts": { "본문": 218, "단원평가": 15, "학업성취도평가": 14 },
    "books": { "cho42": { "name": "...", "images": 108, "pages": ["1","3","10","..."], "partPages": { "단원평가": [1,3,4] } } }
  },
  "titles": { "라이트쎈초421권": "cho42", "쎈52정답": "sen52" },
  "books": { "cho42": { "10": { "1": "ans_img/cho42/cho42_p02_01.png" } } },
  "parts": { "cho42": { "단원평가": { "3": { "7": "ans_img/cho42/cho42_p11_09-2.png" } } } },
  "legacyAnswerPdfDups": [ { "book": "cho42", "answerPdfPage": 3, "no": 3, "files": [ ... ] } ]
}
```

- `books`의 쪽 값은 **교재 본문 인쇄 쪽번호**입니다(`pageBasis: body_page`). 정답지 PDF 쪽이 아닙니다.
- `parts`는 평가편 자체 쪽번호를 쓰는 항목만 담습니다(초4-2 단원평가 15건, 쎈5-2 학업성취도평가 14건). 본문 1~12쪽과 숫자가 겹치므로 평가편은 여기서 구분합니다.
- `titles`의 키는 교재명에서 공백·괄호·기호를 지운 정규화 문자열입니다.
- `legacyAnswerPdfDups`는 같은 정답지 쪽·같은 문항번호에 파일이 2~3개였던 17묶음입니다. 본문 쪽으로 다시 매핑하면서 각 파일이 제 쪽을 갖게 되어, 앱은 이제 접미사와 무관하게 `books`에 적힌 파일을 씁니다.

## 4. 쪽 기준 (2026-11-27 교체 완료)

이전 `books`는 **정답지 PDF 쪽** 기준이었습니다. 이 6권은 정답지가 밀집형이라 정답지 1쪽에 본문 여러 쪽의 답이 몰려 있어, 빠른정답 화면(본문 쪽으로 문항을 부름)에서 이웃 문항 그림이 뜰 수 있었습니다. 2026-11-27에 유성 님 비서가 **247건 전부의 본문 쪽번호(`body_page`)**를 확정해 보내 와서 `books`를 본문 쪽 기준으로 다시 만들었습니다(미확정 0건).

- 초4-2 단원평가(15건)는 평가편 PDF를 확보하지 못해 "2쪽 20문항(1~10번 앞면 / 11~20번 뒷면)" 구성으로 배정했습니다.
- `tg12`(특급기출 중1-2) 1건은 본문 PDF가 없어 정답지의 `154~155쪽` 표기를 근거로 155쪽으로 추정했습니다.
- `sen11` A단계(개념) 12건은 인쇄된 문항번호가 없는 개념 면이라 정답지 표기로 쪽을 확정했습니다.
- 위 항목은 해당 평가편·본문 PDF가 올라오면 100% 대조해 확정할 수 있습니다.

이 6권은 아직 `WINNERS_수학교재_구조_v1`·`WINNERS_수학빠른정답_v1`에 등록되어 있지 않습니다. 등록할 때 쪽은 **본문 쪽**을 넣으면 됩니다.

## 5. 그림을 더 넣는 방법

1. 교재 원본 PDF에서 해당 문항의 정답 그림 부분만 잘라 PNG로 저장
2. `ans_img/{교재키}/` 에 올림(파일 이름은 자유, `manifest.json`에 경로를 적으면 됨)
3. `manifest.json`의 `books`(본문 쪽) 또는 `parts`(평가편 쪽)에 `쪽 → 문항 → 경로`를 추가
4. `ans-img-test.html`에서 그 쪽·문항을 넣어 실제로 뜨는지 확인
