교재·시험지 라이브러리

원본 HWP를 구글 드라이브에 보관하고, 모든 학생이 같은 시험지를 재사용합니다.

새 시험지 등록

다른 HWP 양식은 자동분석에 실패할 수 있으며, 그 경우 선생님 확인 후 원본만 등록할 수 있습니다.

기존 HWP 분석 도구에서 추출한 문항 데이터가 있으면 함께 등록합니다. JSON이 없으면 원본 파일만 저장되며 재시험 자동 조판은 아직 불가능합니다.

등록된 시험지 0개

HWP를 업로드했다고 모든 문항이 자동 인식되지는 않습니다. 기존 분석 도구에서 검증된 HWP 양식은 백업 JSON을 가져와 출제할 수 있고, 나머지 양식은 추가 분석이 필요합니다.

교재 관리 · 학기별/단원별 무제한 확장

초기 115개 파일에 더해 매달 새로운 과를 추가할 수 있습니다. 기존 학습단계 수와 교재 등록 개수는 무관합니다.

➕ 새 단원 빠른 등록

다음 달 교재 추가할 때 사용

예: 중2 동아(윤정미) 5과 → 7과. 기존 단원의 파일명·교재 유형 틀만 복사하고, 새 단원의 실제 문제/답지 파일은 다시 올립니다.

중요: 이전 과의 문항을 새 과로 복사하지 않습니다. 새 교재 파일은 별도로 업로드하며 답지가 포함된 원본은 출력 승인 전까지 차단됩니다. 기존 학생 배정과 성적은 변경되지 않습니다.

① 파일목록 115개 준비

중1 7과·8과, 중2 6과·8과, 공통영어2 3과 — 각 23개. 목록을 등록해도 실제 HWP/PDF 파일이 업로드되지는 않습니다.

② 실제 교재 파일 일괄 업로드

원본 HWP/HWPX/PDF를 여러 개 선택하면 1개씩 차례로 업로드합니다. 10MB 초과 파일은 개별 확인이 필요합니다. 이미 업로드된 파일은 건너뜁니다.

③ 학생용 답지 제거·출력 승인

학생용 보호: 교사용 원본·빠른답지 포함 원본은 학생에게 자동 출력하지 않습니다. HWP/PDF에 답지가 들어 있는 경우 답지 제거한 PDF를 별도 등록하고 선생님이 최종 확인해야 출력 승인됩니다. 문항 무작위 재배열은 문항 데이터 구조화 후에 가능합니다.

교재 목록 · 파일 업로드 현황 (통합본 제외) 0개

이 메뉴는 자료 업로드·답지 확인 상태를 관리합니다. 기존 '학습순서·배정' 메뉴의 단계 수와 무관합니다. 현재 문항을 자동 섞어 출력하는 기능은 기존 검증된 문항 데이터가 등록된 시험지에서만 지원합니다.

✂ 마지막 답지 자동 제외

이미 등록한 HWP/HWPX/PDF 교재를 선택하고, 출력용 PDF에서 마지막 Answer Key 여러 쪽을 제외합니다.

① 교재 선택

원본 HWP/HWPX는 그대로 보관합니다. HWP 문서는 한글 프로그램에서 PDF로 한 번 저장한 다음 아래에서 선택해 주세요. 원본 교재를 다시 업로드할 필요는 없습니다.

② 마지막 답지 감지 및 페이지 확인

PDF를 선택하면 마지막 페이지의 Answer Key 머리말을 확인합니다. 답지 구간이 여러 장이면 모두 제외합니다.
자동 감지 결과는 선생님이 페이지를 확인하는 보조 기능입니다. 앞부분에 정답이 있는 PDF, 이미지형 스캔 PDF, 머리말이 다른 PDF는 자동 확정하지 않습니다. 필요하면 학생용 마지막 페이지를 직접 입력할 수 있습니다.

학생용 PDF 미리보기 · 보이지 않으면 위의 '새 탭에서 열기' 또는 내려받기를 사용하세요.

③ 검토한 PDF를 학생용으로 저장

원본 HWP/HWPX/PDF는 삭제하지 않습니다. 학생용 PDF는 원본과 별도 폴더에 저장하며, 검수 승인 전까지 출력 금지입니다.

HWP 원본을 선택한 경우 같은 교재의 PDF 변환본을 골라 주세요.
